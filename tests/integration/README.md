Integration cases use a transaction-capable isolated MongoDB database. The auth suite covers company registration, login, session revocation, and selected request safeguards. The sites suite covers tenant isolation, site assignment access, validation, and archive/restore audit behavior. The materials suite covers tenant scoping, permission checks, quantity precision, archival rules, and audit records. The suppliers suite covers tenant isolation, role checks, validation, audit records, and archival blocked by open orders. Future inventory suites should use the same isolation pattern.
